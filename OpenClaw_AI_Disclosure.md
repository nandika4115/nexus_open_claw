4. Feature Origin Classification

Feature entries below capture whether a feature was self-authored by developers, generated by AI, or a mix. For each feature: tools/platforms used, representative prompt filename (when applicable), brief output summary, and modification note.

- Feature Name: Session Snapshot
  - Origin: Both
  - Description: Uses `prompts/session-summary.md` with Anthropic Claude via `src/tools/llm-client.ts` to summarize recent session signals (tabs, clipboard, file changes). Output: 1–2 sentence session summaries and extracted snapshot metadata. Modification: developer review and minor edits before writing to `threads/{slug}/sessions/`.

- Feature Name: Thread Resurrection (Resurface Alerts)
  - Origin: Both
  - Description: Composes context-rich notifications using `prompts/thread-resurrection.md` and Claude to surface top insights and open questions. Output: notification body text and suggested actions. Modification: templates and delivery logic implemented by developers; content lightly edited.

- Feature Name: Morning Briefing
  - Origin: Both
  - Description: Aggregates active threads and new papers; uses `prompts/morning-briefing.md` with Claude to narrativize briefing. Output: human-readable briefing delivered to configured channels. Modification: human-curated scheduling and channel integration.

- Feature Name: Connection Engine
  - Origin: Both
  - Description: Computes semantic similarity between thread insights using LLM (Claude) and auxiliary signals (citation overlap from Semantic Scholar). Prompt: `prompts/connection-description.md`. Output: connection entries added to `_connections.yaml` with shared concepts and strength score. Modification: developers tuned thresholds and review candidates before surfacing.

- Feature Name: Literature Watch (Lit Watch)
  - Origin: Both
  - Description: Fetches candidates from arXiv / Semantic Scholar; uses `prompts/relevance-score.md` with Claude to score relevance to thread summaries. Output: ranked `sources.yaml` entries marked `new_unread`. Modification: devs implemented deduplication, rate limiting, and review UI.

- Feature Name: Browser Extension + Bridge
  - Origin: Self-Generated
  - Description: Extension and local API bridge implemented by developers (`browser-extension/` and `browser-extension/api-server.js`). LLMs not used in the bridge runtime; docs or example prompts may have been generated by LLMs.

- Feature Name: Memory Layer (file schemas and index)
  - Origin: Self-Generated
  - Description: YAML/Markdown schema design and file I/O implemented by developers in `src/memory/`. LLM used only for documentation and example content.

- Feature Name: Heartbeat & Scheduler
  - Origin: Self-Generated
  - Description: Scheduler and planner logic implemented by developers (`src/engine/heartbeat.ts`, `planner.ts`). LLM calls are invoked by behaviors but scheduling is developer-coded.
